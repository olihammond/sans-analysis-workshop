# Provenance

This is a standalone teaching repository for a Masters-level SANS data analysis
workshop.

Fitting uses the BSD-licensed [sans-fitter](https://github.com/ai4se1dk/SANS-fitter)
package (0.4 or newer), installed from PyPI. Earlier versions of this repository
bundled an adapted copy of the package in `src/sans_fitter`; it was removed when
the workshop moved to the published release.

The repository as a whole is distributed under the BSD 3-Clause license in
[`LICENSE`](LICENSE).
